# Event Horizon Field Manual

A hands-on, six-module introduction to black holes for the public.

- Live ray-traced black hole (WebGL), ten interactive physics instruments, quizzes and badges
- Real data: M87* reconstructed from the Event Horizon Telescope public release 2019-D01-01 with the EHT eht-imaging pipeline (2019-D01-02); GW150914 strain from LIGO via GWOSC

Open `index.html` in any modern browser, or visit the GitHub Pages site.
